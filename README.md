# 最后一记钟声

《克苏鲁的呼唤》7 版。钟楼停摆十五年后敲了十三下。每一下，都有一个人忘记自己有过孩子——包括你的姐姐。

- **人数**：3 人（2–5 可调）
- **时长**：约 120 分钟
- **结构**：3 章 / 15 节点 / 4 个结局
- **内容**：世界书 18 条（7 条公开 / 11 条守秘人专属），地图地点 9 个

## 结构

| 部分 | 内容 |
|---|---|
| 第一章：灰窑镇 | 寻人墙、姐姐家的四副碗筷、三号窑的班表 |
| 第二章：规矩 | 钟楼机械室、守钟人托马斯、受洗登记簿、门口站着的男孩 |
| 第三章：第十三下 | 钟室与红绳，四个结局 |

## 守秘人要点

1. **每次钟响，让一个 NPC 忘记一件小事。** 不是忘记孩子，是忘记孩子叫什么、忘记给孩子起过名、忘记自己曾抱过一个婴儿。让遗忘一点一点发生。

2. **玛格丽特是情绪支点。** 她不是被骗，她是真的不记得。她说「我没有孩子」时是真诚的。玩家越爱她，越难受。

3. **第十三下之前把时间压紧。** 用真实倒计时（十分钟），让玩家来不及查完所有线索。这是设计，不是缺陷。

## 这个模组在讲什么

钟收的不是人，是「有人记得你」这件事。被收走的孩子还在镇上，在街上走，在学校上课——只是没人认得出他，包括他自己的母亲。
